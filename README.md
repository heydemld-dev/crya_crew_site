# CRYA CREW — сайт-визитка видеопродакшена

Одностраничный статичный сайт: чистый HTML + CSS + JS, без сборки и зависимостей.
Готов к публикации на GitHub Pages.

## Структура

```
index.html              — вся страница
css/style.css           — стили
js/main.js              — меню, анимации появления, бегущая строка
js/hero-fx.js           — анимация главного экрана: красная трава (WebGL) + телевизор с помехами
qr/index.html           — генератор QR-карточек 1080×1920 (открывается в браузере)
qr/make_qr.py           — то же самое скриптом на Python
qr/demo/                — примеры готовых карточек (демо-ссылки)
assets/img/             — сюда положите свои QR-коды, кадр утки и картинку для соцсетей
CNAME                   — ваш домен (для GitHub Pages)
.nojekyll               — отключает обработку Jekyll
```

## Анимация главного экрана

На первом экране — два процедурных эффекта, оба написаны на чистом JS без внешних
видео/библиотек (легко для GitHub Pages, ничего не весит мегабайты):

1. **Красное травяное поле.** Полноэкранный WebGL-шейдер (`#heroCanvas` в `js/hero-fx.js`,
   функция `initGrass`) рисует процедурную траву, которая покачивается от «ветра» и
   реагирует на движение курсора. Палитра строго красно-коричневая
   (`vec3(0.92, 0.20, 0.11)` на кончиках, `vec3(0.24, 0.022, 0.020)` у корней) —
   ни одного зелёного оттенка в коде нет физически.
2. **Телевизор с кадром утки.** Справа стоит нарисованный на CSS корпус ретро-ТВ
   (`.tv` в `css/style.css`), на экране — `<canvas id="tvCanvas">`, который рисует
   кадр и периодически «ловит помехи»: хроматическую аберрацию, сдвиги строк,
   roll-полосу, зерно и скан-линии (функция `initTV` в `js/hero-fx.js`). Помехи
   включаются случайно каждые 1.5–5&nbsp;секунд, чтобы кадр не выглядел статичным.

**Чтобы поставить свой кадр утки:** положите файл `duck.png` (или `.jpg`, тогда
поправьте путь в `js/hero-fx.js`, переменная `shown`) в `assets/img/`. Код сам его
подхватит. Пока файла нет — показывается нарисованная векторная SVG-заглушка
(`assets/img/duck-leather.svg`), чтобы макет не выглядел пустым.

Если захотите вместо статичного кадра показывать короткий видео-луп — замените
`<canvas id="tvCanvas">` на `<video>` с `autoplay muted loop playsinline`, видео-эффекты
помех (CRT-слой) всё равно накладываются через тот же canvas как доп. слой поверх.

Анимация автоматически отключается (замораживается на одном кадре), если в системе
пользователя включён режим «уменьшенная анимация» (`prefers-reduced-motion: reduce`),
и ставится на паузу, когда секция прокручена за пределы экрана — для экономии батареи.

## Что заменить перед публикацией

1. **Telegram-ссылки.** В `index.html` найдите `https://t.me/username_demid` и
   `https://t.me/username_gayane` — вставьте реальные ники. Они встречаются в секции
   «Контакты» (кнопки Telegram).
2. **Ссылка на сайт в метатегах.** Замените `https://example.com/` в `<link rel="canonical">`
   и `<meta property="og:url">` на ваш домен.
3. **QR-коды.** Сгенерируйте карточки (см. следующий раздел), положите файлы
   `qr-demid.png` и `qr-gayane.png` в `assets/img/`. Пока их нет, на странице
   показывается пунктирная заглушка — ничего не ломается.
4. **Картинка для соцсетей.** Добавьте `assets/img/og.jpg` (1200×630 px) — превью при
   отправке ссылки в мессенджерах.
5. **Город в подвале.** Сейчас указана Москва — поправьте, если нужно.

## QR-карточки для Stories (1080×1920)

Два способа, оба дают одинаковый результат.

**Способ 1 — в браузере (ничего ставить не надо).**
Откройте `qr/index.html`, введите имена и ссылки, нажмите «Построить карточки»,
затем «Скачать 1080×1920».

**Способ 2 — скриптом.**

```bash
pip install qrcode pillow
python3 qr/make_qr.py --name "Демид" --url "https://t.me/ваш_ник" --out assets/img/qr-demid.png
python3 qr/make_qr.py --name "Гаянэ" --url "https://t.me/ваш_ник" --out assets/img/qr-gayane.png
```

Флаг `--all` соберёт обе карточки сразу с никами по умолчанию.

Важно: Telegram-ники бывают только латиницей. Если в ссылке кириллица, QR
отсканируется, но ссылка не откроется — страница-генератор об этом предупреждает.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "CRYA CREW site"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, папка `/ (root)` → Save**. Через минуту сайт откроется по адресу
`https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`.

## Подключение своего домена

1. В файле `CNAME` замените `crya-crew.ru` на ваш домен (одна строка, без `https://`,
   без слэша на конце). Если файл не нужен — удалите его и укажите домен
   в настройках Pages вручную.
2. У регистратора домена добавьте DNS-записи.

   Для домена вида `crya-crew.ru` (apex-домен) — четыре A-записи на IP GitHub Pages:

   | Тип | Имя | Значение |
   |-----|-----|----------|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |

   Для поддомена `www` — одна CNAME-запись:

   | Тип | Имя | Значение |
   |-----|-----|----------|
   | CNAME | www | ВАШ_ЛОГИН.github.io |

3. В **Settings → Pages → Custom domain** впишите домен и нажмите Save.
   Дождитесь выпуска сертификата (обычно от нескольких минут до часа),
   затем включите галочку **Enforce HTTPS**.

## Правки на будущее

- Цвета и шрифты меняются в начале `css/style.css` в блоке `:root`
  (переменная `--accent` — акцентный цвет, сейчас красно-оранжевый `#ff3d2e`).
- Порядок секций: `#about` → `#services` → `#projects` → `#contacts`.
  Секции можно менять местами, навигация — обычные якорные ссылки.
- Локальный просмотр: откройте `index.html` двойным щелчком, либо запустите
  `python3 -m http.server` в папке проекта.
- Анимация появления блоков отключается автоматически, если в системе
  включён режим уменьшенной анимации (prefers-reduced-motion).
